# 1. What is Redis?

Redis is an in-memory data store. It's a software program that keeps data in RAM so applications can access it very quickly.

Think of Redis as a separate program running on your computer or server. Your FastAPI application communicates with 
it to store and retrieve data.

For example, imagine your application needs to remember that a user is logged in, or that a particular API request has 
already been processed. Redis can hold that information for quick access.

# 2. Celery
Celery is an asynchronous task queue for Python that executes background tasks outside the main application process. 
It allows applications like FastAPI to submit tasks to a message broker (such as Redis or RabbitMQ) and return responses 
immediately. 

Separate Celery worker processes consume these tasks, execute the functions, and optionally store their 
results in a result backend. 

Celery supports concurrent task execution, retries, scheduling, and distributed processing across multiple machines.
